Panduan resmi modul driver motor servo 16 kanal PCA9685 I2C dari **Tokoasia** (SKU: ID0181).

---

## 📋 Fitur Utama
- Mengendalikan hingga 16 servo secara independen hanya dengan 2 pin komunikasi (I2C SDA & SCL).
- Resolusi PWM 12-bit (4096 step) untuk pergerakan servo yang halus dan akurat.
- Terminal V+ terpisah untuk suplai daya servo eksternal 5V-6V.

---

## 🔌 Skema Wiring (I2C)
- **VCC:** 3.3V / 5V (Daya chip logika)
- **GND:** GND
- **SDA:** SDA Arduino / ESP32
- **SCL:** SCL Arduino / ESP32
- **V+ Terminal:** 5V - 6V DC Adaptor (Daya motor servo)
